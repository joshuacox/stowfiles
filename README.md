# stowfiles
Dotfiles stored in stow

This repo is designed to be cloned to your home directory to ~/.stowfiles  YMMV.  

## Useage

Invoke inside the stowfiles directory like this:

```
stow -vv hypr
```

or use the meta-script:

```
./stow_all.sh
```
